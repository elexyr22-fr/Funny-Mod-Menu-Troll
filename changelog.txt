  result of the session in the menu, logs "client request sent / host confirmed / host refused /

  longer tried as client for the session. Tag CLIENT LIMITED until confirmed in game
- FMMT_VAN hello / ack now carry the mod version and a feature bitmask (old bare hello / ack
  still accepted): FunnyMod.CompatPeers, SETTINGS > NETWORK "Players with Funny Mod Menu Troll
